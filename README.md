# Mohamed Sehli — Portfolio

Portfolio personnel open source. Hébergé sur **GitHub Pages**.

🔗 **Live :** [mohamedsehli.github.io/portfolio](https://mohamedsehli.github.io/portfolio)

---

## Stack

- HTML5 · CSS3 · JavaScript Vanilla
- Aucun framework, aucune dépendance
- Déployé via GitHub Pages (gratuit)

## Features

- ⌨️ Effet de frappe animé dans le hero
- 🎨 Dark mode natif
- 📱 Responsive mobile
- ✨ Scroll reveal animations
- ⬇️ Bouton téléchargement CV
- 🟢 Indicateur de disponibilité animé

## Déploiement

```bash
# 1. Fork ce repo
# 2. Va dans Settings → Pages → Source = main
# 3. Ton site est en ligne sur username.github.io/portfolio
```

## Personnalisation

Modifie `index.html` pour :
- Changer le nom, la description, les projets
- Mettre à jour les liens GitHub / LinkedIn / email
- Ajouter ou retirer des sections

Modifie `style.css` pour changer les couleurs (variables CSS dans `:root`).

## Structure

```
portfolio/
├── index.html       # Page principale
├── style.css        # Tous les styles
├── script.js        # Interactions JS
├── cv/              # Dossier CVs (ajouter les PDFs ici)
│   ├── Mohamed_Sehli_CV_Dev.pdf
│   └── Mohamed_Sehli_CV_CallCenter.pdf
└── README.md
```
